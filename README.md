# SurplusSync 🍲

**A Food Donation and Redistribution Platform**

## About

SurplusSync is a web-based platform that connects food donors with nearby individuals and organizations in need. It aims to reduce food waste and encourage food redistribution.

## Features

* Food donation management
* View available donations
* Find nearby food donation opportunities
* Simple web interface

## Tech Stack

* Python
* Flask
* HTML and CSS
* MySQL

## How to Run

1. Clone the repository.
2. Install the required Python packages.
3. Configure your database settings in a local `.env` file.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in your browser.

## Goal

To reduce food waste and help surplus food reach people who need it.
